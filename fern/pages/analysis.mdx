The analyzer groups structured execution attributes, joins eligible signals through
indexes, and prioritizes recurring scored segments. It does not embed or understand
arbitrary conversations, prove causality or estimate a probability of improvement.

```typescript
import { FeedbackLoop, InMemoryStore } from 'loopiter';
const loop = new FeedbackLoop({ store: new InMemoryStore(), namespace: 'analysis/dev' });
const findings = await loop.analyze({
  dimensions: ['metadata.intent', 'artifacts.prompt'], maximumDimensionDepth: 2,
  signalNames: ['verified_correct'], minimumSupport: 5, minimumScoredCount: 5,
  minimumRecurrence: 2, minimumEffectSize: 0.05, timeBucket: 'week',
  observationWindow: { from: '2026-03-01T00:00:00Z', to: '2026-04-01T00:00:00Z' },
  maximumRecords: 20000,
});
console.log(findings); // Empty until enough eligible scored evidence exists.
await loop.close();
```

## Exact alpha semantics

Within each episode (or execution without an episode), unique positive-weight signals
form a weighted mean. The unit weight is the average signal weight, so long episodes
do not get extra votes merely for having more turns. The global baseline uses all
eligible scored units in the selected cohort, including the segment under inspection.
`effectSize = segment mean - baseline mean`. `minimumEffectSize` gates its **absolute**
magnitude. A recipe must select the direction relevant to its objective.

| Field | Meaning |
| --- | --- |
| executionCount | All executions in the structured segment |
| uniqueSignalCount | Distinct eligible scored signal IDs in the segment |
| episodeCount | Distinct episodes represented by eligible units |
| support / scoredCount | Eligible episode/execution scoring units, not turns |
| effectiveWeight | Sum of normalized unit weights; not a statistical effective sample size |
| meanScore / baselineScore / effectSize | Descriptive weighted comparisons |
| recurrence | UTC observation-time buckets containing eligible scored evidence |
| distinctEntities | Entities represented by eligible units |
| correctionCounts | A corrected JSON value counted at most once per unit |

Recurrence is not proof the same negative effect repeated in every bucket. If your
policy needs that, evaluate it independently. No scored evidence means no finding;
zero weight never passes support, recurrence or effect gates. NaN/infinity fail explicitly.

Choose 1–8 dimensions and depth 1 or 2. Page size is at most 1,000; analysis defaults
to at most 20,000 records **per collection before signal/kind filtering**. It throws
`query_limit` on overflow instead of silently analyzing a truncated dataset. Narrow
windows or explicitly raise the limit only after measuring your workload.

Evidence manifests have version 1, sorted record IDs, both windows and a fingerprint
covering scored values, record revisions and baseline evidence. New evidence can
produce a new candidate. There is deliberately no `Finding.confidence` output.
