## FeedbackLoop

| Method | Behavior |
| --- | --- |
| <code>new FeedbackLoop(store, options?)</code> | Create a loop with optional clock and ID hooks |
| <code>recordExecution(input)</code> | Validate hierarchy and store an execution |
| <code>completeExecution(id, input?)</code> | Add output, merge metadata, and set completion time |
| <code>recordSignal(input)</code> | Validate attribution and confidence, then store evidence |
| <code>analyze(options)</code> | Return recurring segment findings |
| <code>createCandidate(input)</code> | Create a proposal from arbitrary evidence |
| <code>createCandidateFromFinding(input)</code> | Copy finding evidence into a proposal |
| <code>evaluateCandidate(id, name, evaluator)</code> | Append evaluation and move to evaluated |
| <code>approveCandidate(id)</code> | Approve when the latest evaluation passed |
| <code>deployCandidate(id)</code> | Mark approved candidate deployed and supersede previous |
| <code>rejectCandidate(id, reason?)</code> | Reject a non-deployed candidate |
| <code>rollbackCandidate(id)</code> | Supersede deployed candidate and restore previous |
| <code>getExecution(id)</code> | Return one execution |
| <code>getCandidate(id)</code> | Return one candidate |
| <code>listCandidates(options?)</code> | Filter by namespace, target key, and status |
| <code>close()</code> | Close the configured store |

## Deterministic tests

~~~ts
let counter = 0;

const loop = new FeedbackLoop(new InMemoryStore(), {
  clock: () => new Date("2026-09-03T12:00:00.000Z"),
  idFactory: (prefix) => prefix + "_" + ++counter,
});
~~~

## SelfImprovementController

<code>run(input)</code> returns the autonomy level, findings, candidates, deployed candidates, and observable blocks. Experiment and apply modes require an evaluator. Apply mode also requires a deployer.
